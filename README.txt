PyReader —— 基于 Python 的文本小说阅读器
========================================

【启动】
  双击  start.bat
  或命令行:  python reader.py 小说.txt
  或命令行:  python reader.py 书.epub

【支持格式】
  txt           纯文本（自动识别 UTF-8/UTF-16/GBK/Big5）
  md            Markdown（富文本渲染：标题/粗斜体/代码/列表/引用/表格/链接/分隔线）
  epub         电子书（自动解析章节、书名，标准库零依赖）
  html / htm   网页（剥标签后阅读，标题自动识别）
  mobi / azw / azw3 / prc   Kindle 格式（自动解析章节、书名）
  pdf          电子书（仅限有文字层的 PDF；扫描版/图片 PDF 需先 OCR）

  说明：Kindle 的 KFX 格式暂不支持；带 DRM 保护的官方电子书需先用
  Calibre 去除保护后才能打开（本程序不提供 DRM 去除）。

【已实现功能】
  1. 左右双页分页显示（书脊式）
  2. AI 工具：选中文字 → 右键 → 翻译 / 查词典（需在"设置"里填 API Key）
  3. 字体设置（工具栏 → 字体，可改字体和字号）
  4. 目录（自动识别 第X章 / 楔子 / 序章 / 尾声 / 番外 / # 标题）
  5. 翻页 + 书签 + 自动记忆阅读进度
  6. 底部进度条：显示阅读进度，可拖动跳转
  7. 打开大文件时显示加载进度条
  8. 触摸板/触摸屏手势翻页：左右滑动、上下滑动（滑过章尾自动跨章）
  9. 鼠标滚轮 / 触摸板两指滑动翻页（Windows 触摸板以滚轮事件上报滑动）
  10. 排版可调：设置里可调 字体/字号/行距/段落间距/左右边距/上下边距/页边距/书脊
      （默认接近书的排版：字号 15、行距 1.5、段落间距 0.6）
  11. 书的质感版面：深色背景+白色书页、中间书脊阴影、
      每页顶部居中小字页眉（左书名/右章节）、底部居中页码（当前/总页）、
      段落首行缩进两字符、段落间距，页面四周轻微投影
  12. 目录/AI 侧栏默认隐藏（沉浸阅读），工具栏按钮随时显示/隐藏
  13. 单击左右两侧翻页（左=上一页，右=下一页），拖拽仍是选中文字
  14. AI 语音朗读（edge-tts，需联网）：从当前页起朗读、自动跨章续读、
      当前句高亮跟随、暂停/继续/停止、多音色与语速可调
  15. 全文搜索（Ctrl+F / F3）：定位章节、人名、前情，匹配高亮
  16. 阅读主题（夜间/纯白/米黄护眼/浅绿护眼）
  17. 最近打开列表（工具栏“🕘 最近”）
  18. 定时关闭（工具栏“⏰ 定时”，睡前听书自动停）
  19. 支持 epub / html / htm / mobi / azw / azw3 / prc / pdf 格式（自动解析章节与书名）
  20. 双语朗读（工具栏“🌐 双语”）：朗读时 AI 自动翻译并显示原文/译文，
      支持翻成中文或英文，译文随朗读逐句更新
  21. 离线语音朗读（Piper，无需联网）：内置中文 Huayan / 英文 Lessac 两个
      离线音色，首次使用自动从国内镜像下载模型（约 60MB），之后完全本地合成
  22. Markdown 富文本渲染（.md 文件）：标题分级、粗体/斜体/删除线、行内代码、
      围栏代码块、有序/无序/嵌套列表、引用块、表格、链接、分隔线；
      目录按标题级别缩进，正文连续排版（接近专业 md 阅读器）

【快捷键】
  左箭头 / PageUp      上一页
  右箭头 / PageDown / 空格   下一页
  Ctrl+F              聚焦搜索框（输入即时搜索）
  Enter / F3          下一个匹配；Shift+F3 上一个匹配
  鼠标拖选文字 → 右键 → AI 工具 / 加入书签
  鼠标单击阅读区左侧 28% → 上一页；右侧 28% → 下一页（可悬停看手型）
  鼠标单击中间区域 → 不翻页（方便选字）
  触摸板 / 触摸屏：左右滑或上下滑 翻页（左/上滑=下一页，右/下滑=上一页）
  鼠标滚轮 / 触摸板两指滑动：上下滚动=翻页，横向滚动也支持
  （Windows 触摸板的滑动会被系统转成滚轮事件，已做兼容；mac 触控板用原生手势）

【大文件说明】
  采用"按章节惰性分页"：打开只读文件+扫描目录（后台线程），
  只给当前章节分页并缓存附近章节，因此 10MB、100MB 都能秒开不卡。
  无章节的纯文本会自动按 20 万字符切成伪章节。

【依赖安装】
  pip install PySide6          # 图形界面（标准安装即含 QtMultimedia）
  pip install edge-tts        # 语音朗读（可选，需联网）
  pip install mobi            # Kindle 格式支持（mobi/azw/azw3/prc，可选）
  pip install pymupdf         # PDF 电子书（可选，仅限有文字层的 PDF）
  pip install piper-tts       # 离线语音朗读（可选，无需联网，首次自动下载模型）

【编码说明】
  自动识别 UTF-8 / UTF-16 / GBK(GB18030) / Big5，
  打开网上常见的 GBK 编码 txt 不会再乱码。

【测试文件】
  示例小说.txt      小样张，用于快速体验
  大文件测试.txt    约 28MB / 2000 章，用于测试大文件打开速度

【排版调整】
  工具栏 → 设置 → 排版：可调 字体、字号、行距、段落间距、左右边距、
  上下边距、页边距、书脊，改完点确定立即生效。
  想一屏多字：字号/行距/段落间距调小；想更像书：行距 1.5~1.7、字号 15~17。

【Markdown 渲染（.md）】
  打开 .md 文件时自动启用富文本排版：
    · 标题    H1~H6 逐级缩小加粗，H1 作为分页分节（每个 H1 起新页）
    · 行内    **粗体**  *斜体*  ~~删除线~~  `行内代码`（灰底红字）  [链接](url)（蓝字下划线）
    · 代码块   ``` 围栏，等宽字体 + 浅灰底，超长行自动折行
    · 列表     - / * / + / 1. 有序，支持两空格缩进嵌套
    · 引用     > 左侧竖线 + 灰色文字
    · 表格     | 语法，支持 :-- 左 / :-: 中 / --: 右 对齐；超宽时自动收缩列宽并换行
    · 分隔线   --- / *** / ___
  目录会列出全部标题并按级别缩进；正文采用连续排版（不再每个小标题单独成页）。
  搜索 / 选字 / 朗读 / 书签在 md 下依旧可用（内部维护显示文本↔源文本的偏移映射）。

【侧栏显隐】
  目录/AI 默认隐藏；点工具栏的“目录 / 书签”、“AI 工具”按钮显示/隐藏。

【语音朗读（AI 语音读书）】
  工具栏点“🔊 朗读”即可从当前页开始朗读，自动连续读到全书末尾（自动跨章）。
  播放中再点一次 = 暂停，再点 = 继续；“⏹ 停止”结束朗读。
  朗读到哪一句，页面里那一句会以淡黄色高亮并自动翻页跟随。

  音色/语速：工具栏 → 设置 → 语音朗读：
    中文音色  晓晓（默认）/晓伊/晓墨/云希/云扬/云健/晓北/晓妮/晓臻/云哲
    英文音色  Aria / Jenny / Guy / Sonia / Ryan
    日语音色  Nanami / Keita
    离线音色  Huayan（中）/ Lessac（英），无需联网
    朗读语速  -50% ~ +100%

  依赖：
    pip install edge-tts      # 语音合成（微软 Edge 同款神经语音，免费无需 Key）
    pip install piper-tts     # 离线语音（可选，模型首次自动下载，之后无需联网）
    # PySide6 需包含 QtMultimedia（标准 PySide6 安装即含，用于播放）

  说明：edge-tts 走微软 Azure 语音端点，当前网络直连可用；
  若某网络下直连失败，可自行在系统代理里为 speech.platform.bing.com 配置代理。

【主题】
  工具栏 → 设置 → 主题：夜间（默认）/ 纯白 / 米黄（护眼）/ 浅绿（护眼），
  改完点确定立即生效。

【全文搜索】
  工具栏右侧搜索框（或 Ctrl+F）：输入即时搜索，匹配处以淡黄高亮、
  当前匹配亮橙，Enter/F3 下一个、Shift+F3 上一个，状态栏显示“第 x/y 个”。

【定时关闭】
  工具栏“⏰ 定时”选 15/30/45/60 分钟，倒计时显示在状态栏右侧；
  到点自动停止朗读（睡前听书用）。“关闭定时”可随时取消。

【双语朗读（AI 翻译）】
  读英文书时边听英文、边看中文译文，练听力/阅读。
  工具栏点“🌐 双语”开启（需先在“设置”里配好 AI 的 API Key，如 DeepSeek）。
  开启后朗读时，右侧“🌐 双语翻译”面板逐句显示「原文 / 译文」。

  翻译目标：工具栏 → 设置 → 翻译目标，可选“中文”（听英文看中文）
  或“英文”（听中文看英文）。

  音色：设置里已内置 5 个英文音色（Aria/Jenny/Guy/Sonia/Ryan），
  读英文书时选一个英文音色即可。

【AI 设置（翻译/查词）】
  工具栏 → 设置：
    服务商预设  下拉直接选 OpenAI / DeepSeek / 通义千问 / 本地 Ollama，
                会自动填好 API Base 和模型；也可选"自定义"手填。
    API Key    你的密钥
    API Base   兼容 OpenAI 的地址（预设已填好）
    模型       如 deepseek-chat、deepseek-reasoner、qwen-plus、gpt-4o-mini

  DeepSeek 配置：预设选"DeepSeek"，填你自己的 API Key 即可。
  （官方模型名是 deepseek-chat / deepseek-reasoner；如以后推出 v4，
    把"模型"改成官方给的新名字即可，程序不限制模型名。）

【数据存储位置】
  配置和书签保存在  ~/.pyreader/  目录下（config.json、bookmarks.json）；
  离线语音模型缓存于  ~/.pyreader/piper_models/
